## How people are enrolled

People register at different times, and registration stays open until days before the dinner. So these emails are **not a sequence**, which would count from each person's enrollment day. Each email goes out on its date to everyone registered at that moment. Someone who registers late starts with the next email due and never receives the earlier ones. **Every email is written to stand on its own**, because for a late registrant any of them can be the first.

### Table Leaders: board automations

The Table Leader emails need each person's private Guest link, which only the dinner boards hold, so they run as automations on the **Vision Dinner Guests – March 2027** board:

> When **Dinner date** arrives, **[days before]**, at **10:00 am** Eastern → and only if **Role** is **Table Leader** → send email to **Email**

- The website sets Dinner date on every registration, so registering is the enrollment.
- The site clears Dinner date when Status changes to Cancelled, so a released seat gets nothing more.
- `[First name]` is the Guests › First name column. `[Guest link]` is the Guests › Guest link column, which is filled for Table Leaders only.
- Attach the clint@leadcma.org Gmail account to each new automation once, as with the existing ones.

### Guests: monday campaigns

The guest emails don't need a private link, so they can be sent from **monday campaigns**. They get campaign design, unsubscribe handling, and open and click tracking on each contact's timeline.

- **Audience:** a segment such as "Vision Dinner 2027 – Guests." It needs a field on each contact marking them as a March 2027 guest. The website can set that field at registration and clear it when a seat is released. That change to the plugin isn't built yet.
- **Schedule:** one campaign per date, each scheduled ahead of time for 10:00 am Eastern.
- **Include every Spouse/+1**, a Table Leader's spouse included. They attend as guests.
- **Test first:** confirm that the segment is re-checked when each campaign sends. If it's fixed when the campaign is created, late registrants would be missed and the segment would need refreshing before each send.
- **If campaigns isn't available on your plan,** the same emails can run as board automations like the Table Leader series, with the condition "Role isn't Table Leader."

The confirmations and the dinner-week reminders stay as board automations. They carry logistics everyone needs, including people who have unsubscribed from marketing.

- **Check your plan's automation limit.** About 30 Table Leaders × 13 emails is modest, but the guest series would add thousands of actions if it runs as board automations.
